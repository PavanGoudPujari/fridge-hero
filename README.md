# 🥗 Fridge Hero

Fridge Hero is a modern AI-powered recipe generator that transforms random ingredients into delicious recipe ideas using Gemini AI.

Users simply enter ingredients they already have in their kitchen, click **“Cook Magic”**, and instantly receive:
- A fancy dish name
- A short dish description
- A simple 3-step recipe

This project is built as a single-page web application using only:
- HTML
- CSS
- JavaScript
- Gemini API

Everything is contained inside a single `index.html` file, making it beginner-friendly, lightweight, and easy to run locally.


## 3. Add Your Gemini API Key
